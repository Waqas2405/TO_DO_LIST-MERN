# MERN Stack To-Do List

A full-stack task management web application built using the MERN stack (MongoDB, Express.js, React, and Node.js).

## 🚀 Features
- Add new daily tasks
- Mark tasks as completed
- Delete unwanted tasks
- Responsive user interface

## 🛠️ Tech Stack
- **Frontend:** React, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
